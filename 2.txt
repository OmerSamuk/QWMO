## Blocker 1 — Circular import riski

`operators/pauli.py` içinde şu satır var:

```python
from core.qwmo import BudgetExceeded
```

Ama `core/qwmo.py` da şunu yapıyor:

```python
from operators.pauli import pauli_exclusion
```

Bu circular import yaratır. Üstelik `BudgetExceeded` `pauli.py` içinde kullanılmıyor.

**Düzeltme:**

`operators/pauli.py` içinden şu satırı sil:

```python
from core.qwmo import BudgetExceeded
```

## Blocker 2 — Escape success hâlâ yanlış sayılıyor

`QWMO.run()` içinde:

```python
success = new_fitness < agent.fitness
...
escape_successes += 1
...
if success:
    self.escape_phase_counts[phase] += 1
```

Burada `escape_successes` her executed escape için artıyor; gerçek fitness iyileşmesi için değil. Bu yüzden raporda “success” hâlâ “executed” gibi okunabilir.

**Düzeltme:**

```python
old_fitness = agent.fitness
new_fitness = self._evaluate(new_position)
delta = old_fitness - new_fitness

agent.position = new_position
agent.fitness = new_fitness
agent.stagnation_count = 0

delta_sum += delta

if new_fitness < old_fitness:
    escape_successes += 1
    self.escape_phase_counts[phase] += 1
```

`escape_executed` zaten ayrı tutuluyor; bu iyi.
